# xCubus Product Philosophy

> 이 문서는 xCubus의 **최상위 제품철학 문서**다. 카테고리, UX, 수익화, Growth, 관계 기능 및 관련 데이터·운영 정책을 설계하거나 변경할 때 이 문서를 가장 먼저 참조한다. 하위 문서의 규칙이 충돌하면 이 문서의 원칙을 우선한다.

## 1. 출발점: 인간의 욕망

xCubus는 인간의 자연스러운 욕망인 **이성 · 관계 · 평가 · 자랑 · 칭찬 · 욕망**을 제품의 출발점으로 삼는다.

사람은 자신을 보여주고 싶어 하며, 타인이 자신을 어떻게 볼지 궁금해한다. 피드백과 인정은 다시 공유와 새로운 관계 발견으로 이어진다. xCubus는 이 흐름을 건강하고 신뢰할 수 있는 경험으로 설계한다.

## 2. Human Desire Loop

공식 제품 루프는 다음과 같다.

> **보여주고 싶다 → 남들이 어떻게 볼지 궁금하다 → 평가받는다 → 인정/칭찬을 얻는다 → 공유/자랑한다 → 사람을 발견한다 → 관계가 축적된다 → 다시 보여준다**

이 루프의 각 단계는 단독 기능이 아니라 서로 연결된 사용자 가치다.

| 루프 단계 | 제품 설계 의미 |
| --- | --- |
| 보여주고 싶다 | 낮은 마찰의 사진·영상 업로드와 상황에 맞는 질문 작성 |
| 평가받는다 | 빠르고 공정한 YES/NO 반응, 안전한 댓글과 신뢰도 표시 |
| 인정/칭찬을 얻는다 | 결과를 정량 데이터와 맥락 있는 피드백으로 전달 |
| 공유/자랑한다 | Look Book, 결과 공유, 기록 가능한 나의 변화 |
| 사람을 발견한다 | 취향·상황·관심사를 바탕으로 한 콘텐츠와 사용자 발견 |
| 관계가 축적된다 | 반복적인 상호작용을 관계 자산으로 축적하되 사용자의 통제권 보장 |
| 다시 보여준다 | 긍정적인 재방문과 새로운 표현으로 이어지는 선순환 |

## 3. 수익화 연결 원칙

수익 모델은 다음 가치 흐름을 따른다.

> **Human Desire Loop → Result → Boost → Report → xCubus+ → Share → 신규유입 → Relationship Asset**

| 단계 | 사용자 가치와 수익화 역할 |
| --- | --- |
| Result | 기본 결과와 피드백은 신뢰를 만들며, 핵심 경험으로 유지한다. |
| Boost | 사용자가 원하는 경우 도달·발견 가능성을 높이는 선택형 부가 기능으로 설계한다. |
| Report | 기간·카테고리·반응 패턴을 해석하는 심화 리포트로 확장한다. |
| xCubus+ | 저장, 분석, Look Book 관리 등 명확한 부가가치를 제공하는 유료 멤버십이다. |
| Share | 사용자가 자발적으로 결과와 표현을 공유하도록 돕는다. |
| 신규유입 | 공유를 통해 새 사용자가 자연스럽게 유입되도록 한다. |
| Relationship Asset | 반복된 긍정적 상호작용과 취향 신호가 사용자 통제 아래 장기 관계 자산이 된다. |

## 4. 비착취 원칙

인간의 욕망을 서비스 성장 동력으로 활용하되, 사용자를 소모시키거나 평가 데이터의 신뢰를 무너뜨리는 설계는 배제한다.

- 가짜 칭찬, 허위 반응, 결과 조작을 사용하지 않는다.
- 유료 기능이 투표 결과·랭킹·신뢰도 자체를 왜곡하지 않게 한다.
- 열등감, 불안, 비교 피로를 의도적으로 자극하는 문구·알림·노출 구조를 만들지 않는다.
- Dark Pattern, 강제 결제 유도, 숨겨진 제한, 과도한 알림을 사용하지 않는다.
- 평가 결과는 충분한 표본·신뢰도·맥락을 함께 보여 주며, 확정적 판단처럼 과장하지 않는다.
- 관계와 발견 기능은 차단·공개 범위·알림 등 사용자의 통제권을 기본값으로 존중한다.

## 5. 설계 검증 질문

새 기능을 제안하거나 구현하기 전, 다음 질문에 답한다.

1. 이 기능은 Human Desire Loop의 어느 단계를 건강하게 강화하는가?
2. 사용자에게 제공되는 Result·Boost·Report·xCubus+의 가치가 명확한가?
3. 투표·랭킹·관계 데이터의 신뢰와 공정성을 훼손하지 않는가?
4. 사용자의 선택권·안전·자존감을 해치거나 Dark Pattern을 만들지 않는가?
5. 장기적인 Relationship Asset과 재방문에 기여하는가?
